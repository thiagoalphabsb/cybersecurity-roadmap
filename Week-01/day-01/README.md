## ❓ Pergunta do Dia
*Como um computador transforma um programa armazenado em disco em algo que está efetivamente sendo executado?*

---

## 🛠️ Comandos Aprendidos

| Comando | Para que serve | O que observei |
| :--- | :--- | :--- |
| `pwd` | Mostra diretório atual | Caminho do laboratório |
| `ls -la` | Lista arquivos | Permissões e arquivos ocultos |
| `ps` | Mostra processos | Processos ativos |
| `ps aux` | Lista processos detalhadamente | Usuário/PID/CPU/MEM |
| `df -h` | Mostra uso de disco | Espaço disponível |
| `free -h` | Mostra uso de memória | RAM disponível |
