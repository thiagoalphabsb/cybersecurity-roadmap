# Protocolo de Evidências e Sanitização

Todas as evidências deste repositório foram higienizadas para garantir a privacidade e segurança
do ambiente de testes.

## Diretrizes de Anonimização
- Nomes de usuários reais foram substituídos por identificadores genéricos (`ACC-001`, `ACC-002`, etc.).
- Domínios e e-mails pessoais foram alterados para `exemplo.com` ou mascarados (`us***@email.com`).
- Senhas, hashes reais, tokens e códigos de recuperação foram completamente omitidos das capturas de
tela e logs.
