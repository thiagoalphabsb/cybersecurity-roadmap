## 🔗 Relação com a documentação

As evidências não devem ser interpretadas isoladamente. O fluxo recomendado é:

**Atividade → Documentação → Evidência → Resultado → Aprendizado**

## 🔐 Revisão de segurança

Antes de publicar uma nova evidência, verificar:

- Não há senhas, tokens ou chaves.
- Não há dados pessoais desnecessários.
- Informações internas foram sanitizadas quando necessário.
- IPs e nomes de máquinas são de laboratório ou foram publicados intencionalmente.
- A captura demonstra exatamente o resultado descrito.

## 🧹 Regra para novas evidências

Use:

`week-XX-day-YY-descricao.png`

ou, para projetos independentes:

`projeto-etapa-descricao.png`

Evite espaços, nomes genéricos e múltiplas versões da mesma captura.
