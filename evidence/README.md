As evidências estão agrupadas por contexto sempre que possível.

### 📚 Outras evidências

As demais capturas permanecem nos caminhos históricos utilizados pelas semanas anteriores. Novas evidências devem seguir o padrão definido abaixo.

## 🔗 Relação com a documentação

**Atividade → Documentação → Evidência → Resultado → Aprendizado**

Uma captura isolada tem pouco valor. O objetivo é sempre explicar o que foi realizado e o que a evidência comprova.

## 🧹 Convenção para novas evidências

Use:

`week-XX-day-YY-descricao.png`

ou, para projetos independentes:

`projeto-etapa-descricao.png`

Evite espaços, nomes genéricos e múltiplas cópias da mesma captura.

## 🔐 Checklist de publicação

Antes de adicionar uma evidência:

- [ ] Não contém senhas, tokens ou chaves.
- [ ] Não contém dados pessoais desnecessários.
- [ ] IPs e nomes de máquinas são de laboratório ou foram sanitizados.
- [ ] O conteúdo corresponde ao que está descrito na documentação.
- [ ] A captura está no diretório correto.
- [ ] Não existe outra cópia da mesma evidência.
