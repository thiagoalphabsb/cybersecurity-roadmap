# 📄 Documentation Index

Documentação complementar do Cybersecurity Roadmap.

## 📚 Conteúdo

A pasta reúne registros técnicos, anotações de laboratório e relatórios que complementam os READMEs semanais e os projetos.

## 🗂️ Organização

### Registros de laboratório
Arquivos relacionados a atividades práticas e comandos aprendidos.

### Relatórios de incidentes
Documentos de troubleshooting e investigação técnica.

> Novos relatórios de incidente devem preferencialmente usar Markdown e seguir: **Contexto → Sintoma → Evidências → Hipóteses → Validação → Causa → Ação → Resultado → Lições aprendidas**.

## ✍️ Convenção de nomes

Use nomes em inglês, minúsculos e separados por hífen:

`week-07-day-01-python-basics.md`

`incident-001-description.md`

Evite novos arquivos com espaços, mistura de maiúsculas/minúsculas ou extensões diferentes para o mesmo tipo de documentação.

## 🔐 Segurança

Nunca publicar:

- Senhas
- Tokens
- Chaves privadas
- Cookies de sessão
- Dados pessoais desnecessários
- Credenciais reais
- Informações internas não autorizadas
