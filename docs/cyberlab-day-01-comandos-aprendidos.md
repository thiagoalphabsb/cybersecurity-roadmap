## Comandos aprendidos

| Comando | Para que serve | O que observar |
|---|---|---|
| `pwd` | Mostra o diretório atual | Caminho do laboratório |
| `ls -la` | Lista arquivos, inclusive ocultos | Permissões e arquivos ocultos |
| `ps` | Mostra processos ativos | Processos em execução |
| `ps aux` | Lista processos detalhadamente | Usuário, PID, CPU e memória |
| `df -h` | Mostra uso de disco | Espaço disponível |
| `free -h` | Mostra uso de memória | RAM disponível |
