5. ANÁLISE TÁTICA E CORRELAÇÃO DE EVIDÊNCIAS
-------------------------------------------------------------------------------
O que foi observado:
- Entre 08:12:05 e 08:14:48 foram registradas 12 tentativas de login com erro (Event ID 4625) originadas do IP remoto 192.168.1.105.
- As tentativas utilizaram como alvos os nomes de usuário 'Administrator' (8 tentativas) e 'ThiagoAdmin' (4 tentativas).
- Às 08:15:22, ocorreu um logon bem-sucedido (Event ID 4624) para a conta 'ThiagoAdmin'.

Possível relação entre os eventos:
- O padrão indica uma tentativa de força bruta (Brute Force / Password Spraying) vinda do host 192.168.1.105, seguida por um acesso bem-sucedido. 
- A alteração no Logon Type indica que o atacante pode ter obtido sucesso na credencial do usuário 'ThiagoAdmin' após sequências de erro.

Evidências coletadas:
- Registros extraídos via PowerShell (Get-WinEvent) contendo IDs 4624 e 4625.
- Endereço IP de origem remota (192.168.1.105) capturado na mensagem do evento.

-------------------------------------------------------------------------------
6. RESOLUÇÃO DO DESAFIO DO DAY 04
-------------------------------------------------------------------------------
Cenário: Dezenas de eventos 4625 para o mesmo usuário seguidos de um 4624.

Cadeia de Investigação / Próximos Passos:
1. Origem e Logon Type:
   - Verificar no evento 4624 se o IP de origem e o Logon Type coincidem com os dos eventos 4625 prévios (confirmar se a invasão veio do mesmo ator).
2. Investigação Pós-Exploração (O que aconteceu depois?):
   - Mapear os processos criados logo após o logon bem-sucedido (Event ID 4688 - Process Creation).
   - Verificar novas conexões de rede ativas associadas ao PID gerado (Get-NetTCPConnection).
   - Checar modificações de grupos ou privilégios (Event IDs 4728, 4732 - Adição em grupos privilegiados).
   - Investigar criação ou alteração de Serviços/Tarefas Agendadas para persistência (Event ID 7045 / Event ID 4698).

-------------------------------------------------------------------------------
7. CONCLUSÃO
-------------------------------------------------------------------------------
A análise de Event Logs provou a eficácia da correlação temporal entre falhas (4625) e sucessos (4624) na identificação de incidentes de autenticação. A retenção das evidências em formato textual permite alimentar pipelines de SIEM e documentar formalmente o relatório de resposta a incidentes (IR).
