--- File: analisador_logs.py ---
# Week 07 - Day 03
# Analisador de eventos de login com exercicios integrados

eventos = [
    {"usuario": "ana", "ip": "192.168.1.10", "tentativas": 2},
    {"usuario": "carlos", "ip": "10.10.10.20", "tentativas": 7},
    {"usuario": "joao", "ip": "172.16.0.15", "tentativas": 12},
    {"usuario": "ana", "ip": "192.168.1.10", "tentativas": 3},
    {"usuario": "admin", "ip": "203.0.113.50", "tentativas": 9},
    {"usuario": "mariana", "ip": "192.168.1.88", "tentativas": 10}
]

limite = 8

total_eventos = 0
total_alertas = 0
eventos_criticos = 0

print("=== ANALISADOR DE EVENTOS DE LOGIN ===\n")

for evento in eventos:
    total_eventos += 1

    usuario = evento["usuario"]
    ip = evento["ip"]
    tentativas = evento["tentativas"]

    print(f"Usuario: {usuario}")
    print(f"IP: {ip}")
    print(f"Tentativas: {tentativas}")

    if usuario == "admin":
        print("[INVESTIGACAO] Evento associado a conta sensivel (admin)!")

    if tentativas >= 10:
        eventos_criticos += 1

    if tentativas >= limite:
        total_alertas += 1
        print("STATUS: ATENCAO - revisar evento")
    else:
        print("STATUS: NORMAL")

    print("-" * 35)

print("\n=== RESUMO DA ANALISE ===")
print(f"Total de eventos: {total_eventos}")
print(f"Eventos para revisao (>= {limite} tentativas): {total_alertas}")
print(f"Eventos abaixo do limite: {total_eventos - total_alertas}")
print(f"Eventos criticos (>= 10 tentativas): {eventos_criticos}")

# Week 07 - Day 03
# Analisador com agrupamento de tentativas por usuario

eventos = [
    {"usuario": "ana", "ip": "192.168.1.10", "tentativas": 2},
    {"usuario": "carlos", "ip": "10.10.10.20", "tentativas": 7},
    {"usuario": "joao", "ip": "172.16.0.15", "tentativas": 12},
    {"usuario": "ana", "ip": "192.168.1.10", "tentativas": 3},
    {"usuario": "admin", "ip": "203.0.113.50", "tentativas": 9},
    {"usuario": "mariana", "ip": "192.168.1.88", "tentativas": 10}
]

totais_por_usuario = {}

for evento in eventos:
    usr = evento["usuario"]
    tentativas = evento["tentativas"]

    if usr in totais_por_usuario:
        totais_por_usuario[usr] += tentativas
    else:
        totais_por_usuario[usr] = tentativas

print("=== RESUMO AGREGADO POR USUARIO ===")
for usr, total in totais_por_usuario.items():
    print(f"Usuario: {usr:<10} | Total acumulado de tentativas: {total}")

1. Qual é a diferença entre uma lista e um dicionário?
   - Lista (`list`): Coleção ordenada de elementos acessada por índices numéricos sequenciais (`0, 1, 2...`). Ideal para sequências e listas de dados.
   - Dicionário (`dict`): Coleção de pares chave-valor (`key: value`) acessada pelo nome da chave (ex: `evento["usuario"]`). Ideal para representar estruturas com múltiplos atributos.

2. O que o for faz nesse script?
   - Automatiza a iteração sobre a lista `eventos`. A cada ciclo, ele atribui o registro corrente à variável `evento`, aplicando o bloco de código a todos os itens sem duplicação de código.

3. Por que usamos total_alertas += 1?
   - É o operador de atribuição com adição, equivalente a `total_alertas = total_alertas + 1`. Ele incrementa o contador toda vez que a condição de alerta é atendida.

4. O que acontece se alterarmos o limite de cinco para oito?
   - A sensibilidade da regra diminui. Apenas eventos com 8 ou mais tentativas gerarão alerta (reduzindo os alertas gerados para o conjunto de dados).

5. Como poderíamos adaptar o script para analisar registros reais de autenticação do Linux?
   - Lendo o arquivo `/var/log/auth.log`, filtrando linhas com "Failed password", extraindo IP, data e usuário via expressões regulares (`re`) ou `.split()`, e inserindo os dados extraídos em dicionários dentro da lista `eventos`.
