--- File: detector_login.py ---
# Week 07 - Day 02
# Detector simples de tentativas de login

usuario = "analista"
ip_origem = "192.168.1.50"
tentativas = 7
limite = 5

print("=== ANALISE DE AUTENTICACAO ===")
print(f"Usuario: {usuario}")
print(f"IP de origem: {ip_origem}")
print(f"Tentativas de login: {tentativas}")

if tentativas > limite:
    print("ALERTA: quantidade de tentativas acima do limite!")
else:
    print("STATUS: quantidade de tentativas dentro do limite.")

if tentativas >= 10:
    print("PRIORIDADE: investigar com urgencia.")
elif tentativas >= 5:
    print("PRIORIDADE: revisar os registros de autenticacao.")
else:
    print("PRIORIDADE: monitoramento normal.")


--- File: detector_login_funcao.py (Desafio Extra) ---
# Week 07 - Day 02
# Detector com funcao de classificacao de eventos

def classificar_tentativas(tentativas):
    if tentativas >= 10:
        return "Suspeito - investigar"
    elif tentativas >= 5:
        return "Atençao"
    else:
        return "Normal"

# Dados de teste
usuario = "analista"
ip_origem = "10.10.10.20"
tentativas_evento = 12

classificacao = classificar_tentativas(tentativas_evento)

print("=== ANALISE DE AUTENTICACAO (MODO FUNCAO) ===")
print(f"Usuario: {usuario}")
print(f"IP de origem: {ip_origem}")
print(f"Tentativas: {tentativas_evento}")
print(f"Classificaçao: {classificacao}")

1. Qual é a diferença entre str, int e bool?
   - `str` (String): Sequência de caracteres/texto (ex: "192.168.1.1").
   - `int` (Integer): Números inteiros sem casas decimais (ex: 7).
   - `bool` (Boolean): Valor lógico verdadeiro ou falso (`True` ou `False`).

2. Qual é a diferença entre > e >=?
   - `>` (Maior que): Retorna True apenas se o valor for estritamente maior.
   - `>=` (Maior ou igual): Retorna True se o valor for maior ou exatamente igual.

3. Para que servem if, elif e else?
   - `if`: Avalia a primeira condição lógica.
   - `elif`: Avalia condições secundárias caso as anteriores sejam falsas.
   - `else`: Executa o bloco padrão se nenhuma condição anterior for satisfeita.

4. Por que sete tentativas de login não são prova definitiva de um ataque?
   - Podem ser causadas por erro humano, aplicações legadas com credenciais desatualizadas ou falhas de sincronização. A análise defensiva exige validação de contexto e logs adicionais.

5. Como você evoluiria esse script para analisar um arquivo de logs real?
   - Adicionando leitura de arquivos (`open()`), parsing de linhas (ex: extração via Regex ou `split()`), iteração sobre múltiplos registros e integração com parsing JSON/CSV.
