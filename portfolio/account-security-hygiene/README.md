# 🔐 Account Security Hygiene

## Objetivo

Aplicar princípios de segurança de contas em um cenário prático, avaliando controles que reduzem riscos associados a credenciais e acesso.

## Controles avaliados

- Senha forte
- Gerenciador de senhas
- MFA
- Métodos de recuperação
- Sessões desconhecidas
- Aplicativos conectados
- Permissões desnecessárias

## Ferramentas e conceitos

- Password Manager
- Bitwarden
- MFA / 2FA
- Gestão de credenciais
- Controle de sessões
- Princípio do menor privilégio
- Recuperação de conta

## Metodologia

Cada conta foi analisada individualmente para identificar lacunas de segurança e registrar ações de melhoria.

O objetivo foi transformar recomendações genéricas de segurança em uma checklist prática e verificável.

## Competências demonstradas

- Identity and Access Management — fundamentos
- Account Security
- MFA
- Credential Management
- Least Privilege
- Security Hygiene
- Risk Identification
- Documentation

## Resultado

O projeto consolidou uma abordagem prática para avaliar a postura de segurança de contas e identificar controles que podem reduzir riscos de comprometimento.
