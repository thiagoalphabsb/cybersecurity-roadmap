## Segurança e investigação

O estudo foi orientado não apenas para aprender comandos, mas para entender o que cada informação representa em uma investigação.

**Processo → consumo de recurso → PID → serviço**

**Porta → socket → processo → serviço**

**Usuário → grupo → privilégio → ação**

**Evento → log → evidência → investigação**

## Privilégios

Foram praticados conceitos relacionados a sudo, permissões, usuários, grupos, privilégios administrativos e rastreabilidade de ações.
