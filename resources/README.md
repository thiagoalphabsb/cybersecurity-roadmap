# 📚 Central de Recursos & Materiais de Estudo (CyberLab)

Esta pasta reúne a curadoria de materiais, guias de referência, ferramentas e links úteis utilizados ao longo do roadmap de **Cybersecurity**. 

O objetivo é manter uma base de conhecimento acessível para apoio rápido durante as práticas em laboratório.

---

## 📌 Categorias de Recursos

| Categoria | Descrição | Principais Itens |
| :--- | :--- | :--- |
| 🛠️ **Ferramentas & Utilities** | Softwares e frameworks utilitários | Wireshark, Nmap, Burp Suite, Metasploit |
| 📄 **Cheatsheets** | Guias rápidos de comandos e sintaxe | Linux CLI, Bash, SQLi, Nmap, Git |
| 🌐 **Plataformas de Treino** | Ambientes práticos e máquinas CTF | TryHackMe, Hack The Box, PortSwigger |
| 📖 **Documentação & Livros** | Guias oficiais e leituras de referência | ISO 27001, MITRE ATT&CK, NIST |

---

## 📑 Detalhamento por Categoria

### 🛠️ Ferramentas Recomendadas
* **Redes & Análise de Tráfego:**
  * [Wireshark](https://www.wireshark.org/) — Analisador de protocolos de rede.
  * [Nmap](https://nmap.org/) — Mapeamento de rede e scanner de portas.
* **Segurança Web & Pentest:**
  * [Burp Suite](https://portswigger.net/burp) — Plataforma para testes de segurança em aplicações web.
* **Sistemas & Hardening:**
  * [LinPEAS / WinPEAS](https://github.com/carlospolop/PEASS-ng) — Scripts para enumeração e elevação de privilégios.

---

### 📄 Cheatsheets & Guias Rápidos
* **Linux & Terminal:** Comandos fundamentais para navegação, permissões (`chmod`/`chown`) e gerenciamento de processos.
* **Redes:** Comandos para diagnósticos (`netstat`, `ss`, `ip`, `dig`, `tcpdump`).
* **Git & Versionamento:** Fluxo de trabalho para staging, commits e envio de relatórios ao GitHub.
