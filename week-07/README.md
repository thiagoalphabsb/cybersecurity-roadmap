# Week 07 — Python 🐍

> Introdução à automação e programação aplicada à Cibersegurança.

## 🎯 Objetivo

Desenvolver fundamentos de Python suficientes para automatizar tarefas simples de administração, análise e segurança.

## 🧭 Foco da semana

- Sintaxe e tipos básicos
- Variáveis e estruturas de dados
- Condicionais e loops
- Funções
- Manipulação de arquivos
- Tratamento de erros
- Módulos
- Automação de tarefas
- Aplicações simples em Cybersecurity

## 🧪 Prática

Os exercícios devem priorizar problemas próximos da realidade de infraestrutura e segurança, por exemplo:

- leitura e análise de arquivos de log;
- busca de padrões;
- validação de IPs;
- inventário simples;
- automação de tarefas repetitivas;
- processamento de evidências textuais.

## 📁 Evidências

As evidências desta semana serão adicionadas conforme os exercícios forem concluídos.

## 📝 Registro diário

Cada dia deve registrar:

1. Objetivo
2. Conceitos estudados
3. Código produzido
4. Resultado
5. Problemas encontrados
6. Solução
7. Aprendizado
8. Próximo passo

## 🔗 Relação com o roadmap

Python será utilizado posteriormente em automação, análise de dados, segurança, SOC e tarefas repetitivas.
